About abwex

abwex.com is a free A/B test significance calculator. Enter your control and variant data to get instant statistical analysis including z-test p-values, confidence levels, visual comparisons, and a clear winner/not-enough-data verdict.

Features

  • Frequentist analysis: z-test, p-value, confidence levels (90%, 95%, 99%)
  • Visual bar chart with 95% confidence interval error bars
  • Relative improvement calculation
  • Bayesian mode: probability that Variant beats Control
  • Sample size calculator: plan tests before running them
  • Clear verdict: winner or not enough data

The Math

The significance test uses a two-proportion z-test with pooled standard error. The formula is:

z = (p2 - p1) / sqrt(p_pooled * (1 - p_pooled) * (1/n1 + 1/n2))

The Bayesian mode calculates P(B > A) using Beta distributions with uniform priors (Beta(1,1)).
