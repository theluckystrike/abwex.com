FAQ

What is the Chi-Square test?
It compares observed vs expected frequencies. Goodness-of-Fit checks distribution; Independence checks association between two variables.
How is p-value computed?
Using regularized incomplete gamma function P(a,x) via series expansion (accurate for df 1–20).
What is Cramér's V?
Effect size for contingency tables: V = √(χ²/(n·min(r-1,c-1))). 0 = no association, 1 = perfect.
