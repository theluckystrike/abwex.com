# ABWex -- A/B Test Statistical Significance Calculator

**[-> Use ABWex (live tool)](https://abwex.com/)**

ABWex is a free A/B test calculator that provides both frequentist Z-test and Bayesian Beta-Binomial analysis. Compare up to 4 variants simultaneously, project revenue impact, and plan sample sizes -- all running entirely in your browser with no data sent to any server.

## Features

- Frequentist Z-test with p-value, Z-score, and confidence intervals
- Bayesian Beta-Binomial analysis with P(B beats A) and expected loss
- Multi-variant comparison for up to 4 variants (A/B/C/D)
- Revenue impact projections based on conversion rate differences
- Sample size pre-calculator with power curves and duration estimates
- Formula transparency showing the exact math behind every result
- 100% client-side -- your data never leaves your browser
- Open source -- inspect the code yourself

## Tech Stack

- Vanilla JavaScript (no frameworks, no build step)
- Static HTML hosted on GitHub Pages
- Cloudflare DNS + SSL
- Zero dependencies, zero tracking, zero cookies
